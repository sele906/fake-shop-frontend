# 안삼 (ANSAM)

> 사고 싶은 마음만 사고, 실제 물건은 사지 않는 가짜 쇼핑몰

쇼핑몰의 탐색, 장바구니, 쿠폰, 결제, 배송 조회 경험을  
실제 구매 없이 즐길 수 있도록 만든 인터랙티브 웹 프로젝트입니다.

## 💡 기획 의도

온라인 쇼핑에서 상품을 둘러보고 장바구니에 담는 과정 자체가  
하나의 재미가 될 수 있다는 점에서 출발했습니다.

실제 결제 기능 없이도 쇼핑몰 특유의 인터랙션과 도파민을 경험할 수 있도록  
가짜 결제, 가짜 배송 조회, 쿠폰, 히든 미션 등의 기능을 구현했습니다.

## ✨ 주요 기능

- 12개 대분류 · 83개 소분류 카테고리별 상품 탐색
- 상품 상세 정보, 별점 분포와 리뷰 더보기, 연관 상품 추천
- 옵션·수량 단위 장바구니 관리
- 58종 쿠폰 발급과 혼합 중복 할인 적용
- 사이트 곳곳에 숨겨진 히든 미션 6종과 업적 쿠폰
- 가짜 결제, 배송 경로 애니메이션, 절제·도파민 게이지
- 서버 없이 링크 하나로 공유되는 영수증
- LocalStorage 기반 상태 유지와 탭 간 실시간 동기화
- 반응형 웹 UI

## 🔍 주요 구현 내용

### JSON 기반 상품 데이터 구성

서버 없이도 다양한 상품을 탐색할 수 있도록
상품 1,446개, 리뷰 18,872건, 스펙 8,909행, 브랜드 384개,
카테고리 95개(대분류 12 · 소분류 83), 쿠폰 58종을 JSON 구조로 설계했습니다.

상품마다 서로 다른 리뷰 수, 별점, 작성자와 작성일을 가지도록
데이터 생성 과정을 자동화했습니다.

### LocalStorage 상태 유지

로그인이나 서버 없이도 장바구니와 쿠폰 상태가 유지되도록
LocalStorage에 필요한 사용자 데이터를 저장했습니다.

저장된 데이터가 없거나 형식이 올바르지 않은 경우를 고려해
기본값으로 복구하도록 처리했습니다.

### 쿠폰 중복 발급 방지

동일한 미션을 반복해도 쿠폰이 여러 번 발급되지 않도록
미션 달성 기록을 쿠폰함과 별도의 저장소에 남겼습니다.

달성 기록 저장, 쿠폰함 반영, 알림 표시는 한 곳에서 처리해
미션이 어느 화면에 있든 지급 규칙과 알림 모양이 같도록 했습니다.

### 가짜 결제와 배송 인터랙션

실제 결제가 이루어지지 않는 프로젝트 특성을 활용해
결제 실패, 배송 이동, 상품 도착 등의 과정을 위트 있는 UI로 구성했습니다.

배송 화면은 SVG 경로 위를 이동하는 6단계 지도로 만들고,
도착 시점에 맞춰 애니메이션이 끝나도록 구성했습니다.

### 링크 하나로 공유되는 영수증

서버 없이 영수증 내용을 전부 주소에 실었습니다.
JSON을 UTF-8로 바꾼 뒤 Base64URL로 인코딩해 `/receipt?d=` 뒤에 붙입니다.

상품 데이터를 다시 만들어도 예전에 공유한 링크가 그대로 열리도록 하기 위해서 주소에는 상품 이름과 수량 스냅샷을 담았습니다.

### 탭 간 상태 동기화

한쪽 탭에서 장바구니나 쿠폰을 바꾸면 열려 있는 다른 탭도 따라오도록
`storage` 이벤트를 듣고 저장된 값을 다시 읽어 상태를 맞췄습니다.

## 🧩 트러블 슈팅

### 서버 없이 사용자 상태를 유지하는 문제

문제:

- 새로고침하면 장바구니와 쿠폰 정보가 사라짐
- 동일한 히든 미션이 반복 실행될 수 있음

해결:

- 상태가 변경될 때 LocalStorage에 데이터를 동기화
- 앱 실행 시 저장 데이터를 초기 상태로 복원
- 쿠폰과 미션에 고유 ID를 부여해 중복 여부 확인

### 대량의 상품 및 리뷰 데이터 구성

문제:

- 상품마다 리뷰 수와 내용이 달라 수작업 작성이 어려움
- 리뷰 별점과 상품 평균 별점의 일관성이 필요함

해결:

- 엑셀과 JSON 사전을 활용해 데이터를 생성
- 리뷰 내용에 맞춰 개별 별점을 부여
- 리뷰별 별점의 평균으로 상품 별점을 계산

### 영수증 링크에서 한글 상품명이 깨지는 문제

문제:

- 영수증 내용을 주소에 실으려면 Base64로 인코딩해야 함
- `btoa`는 Latin-1만 받아 한글 상품명에서 예외가 발생

해결:

- `TextEncoder`로 문자열을 UTF-8 바이트로 바꾼 뒤 인코딩
- 주소에 쓸 수 없는 `+` `/` `=`를 `-` `_`로 치환해 Base64URL로 변환
- 주소가 잘리거나 손상된 경우를 대비해 디코딩 실패 시 `null`을 돌려주고 안내 화면으로 대체

### 탭 간 동기화가 서로를 계속 깨우는 문제

문제:

- 다른 탭에서 받은 변경을 그대로 저장소에 되쓰면서 `storage` 이벤트가 무한히 오감
- 반대로 `storage` 이벤트는 값을 바꾼 탭 자신에게는 오지 않아,
  히든 쿠폰처럼 다른 화면에서 저장한 변경을 쿠폰함이 알아채지 못함

해결:

- 저장 직전 기존 값과 비교해 내용이 같으면 쓰지 않도록 차단
- 같은 탭에는 `StorageEvent`를 직접 발생시켜 열려 있는 화면이 새 값을 읽도록 처리
